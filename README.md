# E-commerce Customer Churn Prediction

## Overview
This repository documents a graduate Machine Learning team project on e-commerce customer churn prediction and an ongoing independent portfolio refactor of the analysis.

The academic project followed the CRISP-DM framework and compared Random Forest and XGBoost models to identify customers at risk of churn and translate model findings into practical customer-retention considerations.

### Methodology

### Models
- Random Forest
- XGBoost

### Results from the original coursework
Both models achieved approximately 93% overall accuracy.

For the churn class:
- **XGBoost:** Recall 0.73, F1-score 0.79
- **Random Forest:** Recall 0.68, F1-score 0.77

These results are reported from the original academic team project and will be re-evaluated during the portfolio refactor.

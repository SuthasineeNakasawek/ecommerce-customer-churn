# E-commerce Customer Churn Prediction

## Overview
This project analyzes e-commerce customer data to identify customers at risk of churn and translate model insights into practical customer-retention strategies.

The project follows the CRISP-DM framework and compares Random Forest and XGBoost models.

## Methodology
- Business Understanding
- Data Understanding
- Data Preparation
- Modeling
- Evaluation
- Deployment / Business Application

## Models
- Random Forest
- XGBoost

## Results
Both models achieved approximately 93% overall accuracy.

XGBoost achieved higher performance for the churn class:
- Recall: 0.73
- F1-score: 0.79

Random Forest:
- Recall: 0.68
- F1-score: 0.77
